# Juntos pelos Animais — Araçariguama/SP

Protótipo de landing page estática para apresentação e validação do projeto.

## Publicação no GitHub Pages

1. Envie os arquivos deste diretório para a branch `main` do repositório.
2. No GitHub, abra **Settings → Pages**.
3. Em **Build and deployment**, escolha **Deploy from a branch**.
4. Selecione a branch `main`, a pasta `/ (root)` e clique em **Save**.

A publicação costuma ficar disponível no endereço:

`https://SEU-USUARIO.github.io/juntos-pelos-animais/`

## Observações

- O arquivo principal já se chama `index.html`, como exigido pelo GitHub Pages.
- O protótipo usa Tailwind CSS, Google Fonts e Font Awesome por CDN.
- As imagens fictícias e os links sem dados oficiais devem ser substituídos antes do lançamento definitivo.
- A página inclui `noindex, nofollow` enquanto estiver em validação. Remova essa meta tag quando o site estiver pronto para aparecer nos mecanismos de busca.
